# Feature ideas backlog

Living list, started 2026-11-25. One row per idea, with duplicates merged. Newest evidence first in each row.

**Phase 1 constraints each idea is checked against:**
- **R**: referral-only. No bookings, payments or "book with us" wording (TICO).
- **$**: near-zero running cost.
- **W**: fits the wedge (CAD, Toronto departures, Canadian travellers).
- **T**: honest numbers. Ranges and confidence labels, and the LLM never produces prices (spec §7).

**Effort:** S = under a day of agent time, M = a few days, L = a week or more, or needs a new data source or account.
**Recommendation:** **now** (Stage 1-3), **after Gate A**, **Phase 2**, or **no**.
